# Notes for Claude

This is Steven A.J. Beijer's translation website, maintained by Steven and his brother Michael Beijer. See README.md for the file layout.

- Plain static HTML/CSS on GitHub Pages. No frameworks, no build tools, no JavaScript beyond the footer year.
- Pushing to `main` publishes the live site. Show the person a screenshot or preview of the change and get a yes before pushing.
- Keep both pages consistent: header, footer and buttons are duplicated in `index.html` and `examples.html`, so change both.
- All styling lives in `style.css`. Do not add inline styles.
- Check every change at phone width (about 390 px) as well as desktop: no horizontal scrolling.
- Writing style: UK English, en dashes (–) not em dashes (—).
- Never delete `CNAME`.
